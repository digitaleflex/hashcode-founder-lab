# 05 — Activities

## Workflow

IDÉE → OBJECTIF → PUBLIC → FORMAT → DATE → PRÉPARATION → COMMUNICATION → ACTIVITÉ → SUIVI → BILAN

## Formats

- Mission
- Atelier
- Session
- Challenge
- Meet
- Tech Discovery

## Chaque activité doit définir

- objectif ;
- public ;
- responsable ;
- date ;
- action attendue ;
- résultat attendu ;
- indicateurs de succès ;
- suivi après l'activité.
