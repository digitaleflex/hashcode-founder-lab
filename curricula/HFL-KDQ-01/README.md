# HFL-KDQ-01 — Knowledge, Documentation & Quality

Premier parcours du HashCode Founder Lab consacré au développement des compétences en Knowledge Management, Documentation et QA à travers un projet réel.

## Parcours

1. S01 — Cadrage
2. S02 — Documentation
3. S03 — Travail accompagné
4. S04 — Introduction au QA
5. S05 — Pratique QA
6. S06 — IA & Documentation

## Résultats attendus

Le participant progresse par la boucle : **Apprendre → Pratiquer → Produire → Recevoir du feedback → Améliorer**.

Le parcours aboutit à quatre livrables :

- Bibliothèque de 10 prompts utiles ;
- Checklist QA de JoinHashCode ;
- Squelette du guide d’intégration ;
- Modèle de journal de bord.
