# Exercice — Contexte ou problème ?

## Objectif

Distinguer le **contexte** du **problème à résoudre**.

## Consigne

Pour le chantier HFL-KDQ-01, répondre aux questions suivantes :

1. Pourquoi ce chantier existe-t-il ?
2. Quel problème cherche-t-il à résoudre ?
3. Qui utilisera les ressources produites ?
4. Quels types d’informations doivent être documentés ?
5. Quels résultats doivent être obtenus ?
6. Comment saura-t-on qu’un livrable est réussi ?

## Critère attendu

La réponse doit distinguer clairement :

- la situation actuelle ;
- le besoin ;
- le problème ;
- les utilisateurs concernés ;
- le résultat attendu.

## Preuve

Une synthèse réutilisable dans la charte de cadrage.
