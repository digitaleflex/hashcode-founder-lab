# Séance 3 — Rédaction documentaire

## Finalité

Transformer une information brute en document professionnel, clair et actionnable.

## Objectif

Apprendre à définir le public, structurer le contenu, rédiger clairement et produire une documentation maintenable.

## Notions à préparer

- objectif d'un document ;
- public cible ;
- structure d'une documentation ;
- titres et hiérarchie ;
- clarté et précision ;
- procédures et instructions ;
- exemples ;
- ambiguïtés ;
- règles éditoriales.

## Livrable cible

**Documents structurés + règles éditoriales V1.**
