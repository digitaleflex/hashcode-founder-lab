# Séance 4 — IA, Prompts & Quality Assurance

## Finalité

Utiliser l'IA pour accélérer la production documentaire sans abandonner le contrôle humain sur la qualité.

## Objectif

Apprendre à construire, tester et améliorer des prompts puis à appliquer une démarche QA sur les contenus produits.

## Notions à préparer

- rôle de l'IA dans la documentation ;
- anatomie d'un prompt ;
- contexte et contraintes ;
- résultat attendu ;
- critères d'acceptation ;
- IA comme assistant de structuration ;
- IA comme reviewer ;
- test QA ;
- exactitude, cohérence, complétude, lisibilité et traçabilité.
