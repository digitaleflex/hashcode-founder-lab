# Séance 5 — Consolidation

## Finalité

Assembler les productions réalisées en un ensemble cohérent, utilisable et prêt à être transmis.

## Objectif

Apprendre à effectuer une revue croisée, corriger les incohérences et préparer un kit documentaire fiable.

## Notions à préparer

- revue documentaire ;
- cohérence inter-documentaire ;
- gestion des écarts ;
- versioning ;
- traçabilité ;
- accessibilité ;
- maintenabilité ;
- préparation à la transmission.

## Livrable cible

**Kit documentaire consolidé + journal des décisions et corrections.**
