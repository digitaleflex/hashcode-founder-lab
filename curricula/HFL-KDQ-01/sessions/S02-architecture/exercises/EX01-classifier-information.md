# EX01 — Classifier l'information

## Mission
Classer : syllabus, consigne d'exercice, feedback, checklist QA, compte rendu, guide d'utilisation et résultat d'évaluation.

Pour chaque élément :
1. proposer une catégorie ;
2. justifier ;
3. identifier les chevauchements ;
4. proposer une règle de classement.

## Critère
La classification doit pouvoir être appliquée par une autre personne sans nouvelle interprétation.
