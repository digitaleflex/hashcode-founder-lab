# N06 — Navigation et test de trouvabilité

## Objectif
Vérifier qu'une architecture fonctionne pour un utilisateur réel.

## Architecture vs navigation
L'architecture est le système d'organisation. La navigation est la manière visible dont l'utilisateur se déplace dans ce système.

## Trois chemins
Un contenu peut être retrouvé par :
- navigation hiérarchique ;
- recherche ;
- liens contextuels.

## Test de trouvabilité
Définir une mission précise : « Trouve la grille d'évaluation de la Séance 2. »

Observer où la personne commence, où elle hésite, les catégories choisies et si elle trouve la bonne ressource.

## Règle
Si plusieurs utilisateurs échouent au même endroit, examiner l'architecture avant de conclure que les utilisateurs sont responsables.

## À retenir
Une architecture est validée lorsqu'elle fonctionne pour ses utilisateurs.
