# N07 — Ownership, statut et cycle de vie

## Objectif
Savoir qui est responsable d'un contenu et comment celui-ci évolue dans le temps.

## Ownership
Distinguer :
- créateur ;
- propriétaire ;
- reviewer ;
- utilisateur ;
- mainteneur.

## Statut
Exemple de cycle :
`DRAFT → IN_REVIEW → ACTIVE → DEPRECATED → ARCHIVED`

## Cycle de vie
1. besoin identifié ;
2. création ;
3. review ;
4. publication ;
5. utilisation ;
6. mise à jour ;
7. remplacement ou archivage.

## Risque sans propriétaire
Les contenus vieillissent, plusieurs versions apparaissent et la confiance diminue.

## À retenir
Organiser un contenu ne suffit pas : il faut aussi connaître son responsable et son état.
