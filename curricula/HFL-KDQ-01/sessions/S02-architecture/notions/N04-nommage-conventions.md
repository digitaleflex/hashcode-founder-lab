# N04 — Nommage et conventions

## Objectif
Créer des noms cohérents qui permettent d'identifier rapidement un contenu.

## Convention
Utiliser un identifiant stable et un nom lisible.

Exemple : `HFL-KDQ-01-S02-N01-architecture-information.md`

Structure : **Programme → Séance → Type → Numéro → Nom**.

## Règles
- un identifiant ne change pas sans raison majeure ;
- le nom est descriptif ;
- une convention unique est appliquée ;
- éviter « final-final-vraiment-final » ;
- éviter les abréviations incompréhensibles.

## Version
- v0.x : brouillon évolutif ;
- v1.0 : première version validée ;
- v1.x : amélioration compatible ;
- v2.0 : changement majeur.

## À retenir
Le nommage est une interface : un utilisateur doit comprendre un contenu avant même de l'ouvrir.
