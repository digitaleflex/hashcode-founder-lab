# HashCode Reboot × Founder Lab
# Premium Design & Animation Brief

## Mission

Transformer le storyboard narratif en une expérience de présentation immersive construite en **HTML, CSS et JavaScript**.

L'objectif n'est pas de produire des slides classiques.

Le résultat doit ressembler à une **keynote technologique premium** : narrative, minimaliste, cinématique, interactive et mémorable.

---

# 1. PRINCIPES DE DESIGN

## Une idée par écran

Chaque slide doit répondre à une seule fonction :

- intriguer ;
- faire réfléchir ;
- révéler ;
- expliquer ;
- provoquer une décision.

Ne jamais afficher un mur de texte.

Le présentateur raconte l'histoire. L'écran amplifie le message.

## Hiérarchie visuelle

1. Message principal.
2. Mot ou concept clé.
3. Information secondaire.
4. Détails uniquement si nécessaires.

## Espace négatif

Le vide est volontaire.

Les slides importantes doivent respirer.

---

# 2. DIRECTION ARTISTIQUE

## Atmosphère

- Tech premium
- Futuriste mais crédible
- Minimaliste
- Cinématique
- Haute énergie aux moments clés
- Calme pendant les réflexions

## Palette

Utiliser le branding officiel HashCode Reboot.

- Background : noir profond
- Texte principal : blanc cassé
- Texte secondaire : gris neutre
- Accent : vert HashCode/Reboot

### Règle

Le vert n'est **pas une couleur décorative permanente**.

Il doit signaler :

- une révélation ;
- une action ;
- un progrès ;
- un concept important.

---

# 3. TYPOGRAPHIE

## Headlines

Utiliser :

- Space Grotesk, ou
- Inter Tight.

Caractéristiques :

- très grande taille ;
- poids fort ;
- espacement contrôlé ;
- composition asymétrique possible.

## Texte secondaire

Inter.

Lisibilité absolue.

---

# 4. SYSTÈME D'ANIMATION

## Règle principale

**Les animations doivent raconter quelque chose.**

Aucune animation uniquement parce qu'elle est visuellement jolie.

Chaque mouvement doit servir :

- le rythme ;
- la compréhension ;
- l'émotion ;
- la hiérarchie.

---

# 5. ANIMATIONS SIGNATURE

## A. CINEMATIC FADE

Utilisation :

- ouverture ;
- conclusion ;
- moments de silence.

Effet :

- opacity 0 → 1 ;
- léger déplacement vertical ;
- easing cinématique.

Durée :

600ms à 1200ms selon l'importance.

---

## B. KINETIC TYPOGRAPHY

Pour les mots clés :

# ACTIVATION
# TRANSFORMATION
# CONSTRUIRE
# BÂTISSEURS

Le mot peut :

- apparaître caractère par caractère ;
- grandir ;
- se déplacer ;
- changer d'échelle ;
- remplir progressivement l'écran.

Utilisation rare pour conserver son impact.

---

## C. WORD REVEAL

Phrase construite progressivement.

Exemple :

> Une communauté peut être grande…

Pause.

Puis :

> …et silencieuse.

Le second élément doit provoquer le contraste.

---

## D. SCALE IMPACT

Pour les moments de révélation.

Exemple :

# C'EST POUR CELA QUE VOUS ÊTES ICI.

Le texte démarre légèrement réduit puis atteint son échelle finale avec un impact contrôlé.

Pas de bounce enfantin.

---

## E. MORPHING CONCEPTUAL

Les concepts doivent parfois se transformer.

Exemple :

```
INDIVIDUS
   ↓
TALENTS
   ↓
ÉQUIPES
   ↓
PROJETS
   ↓
IMPACT
```

Chaque niveau remplace visuellement le précédent.

La transformation doit suggérer l'évolution.

---

## F. FLOW ANIMATION

Pour les processus :

```
IDENTIFIER
    ↓
ACTIVER
    ↓
ENGAGER
    ↓
STRUCTURER
    ↓
COLLABORER
    ↓
CONSTRUIRE
```

Une étape s'active.

Puis une ligne lumineuse progresse vers la suivante.

Le vert accompagne le mouvement.

---

## G. PARTICLE / NETWORK MOTION

Utilisation uniquement pour :

- communauté ;
- connexion ;
- collaboration ;
- écosystème.

Créer un réseau discret de points et lignes.

Les éléments peuvent progressivement se connecter.

Ne pas transformer la présentation en fond animé permanent.

---

## H. GLITCH MINIMAL

Autorisé uniquement lors d'une rupture narrative.

Exemple :

> Nous pouvions continuer comme avant.

Puis rupture.

> OU CHANGER LE SYSTÈME.

Un glitch très court peut accompagner la transition.

Durée maximale recommandée : 200ms.

---

## I. SPOTLIGHT

Un concept est dans l'ombre.

Puis il devient lumineux.

Exemple :

# LE PROBLÈME N'ÉTAIT PAS LE POTENTIEL.

Le mot POTENTIEL reste discret.

Puis :

# LE PROBLÈME ÉTAIT L'ACTIVATION.

ACTIVATION devient la source visuelle dominante.

---

# 7. INTERACTIONS

## Navigation

Supporter :

- ArrowRight
- ArrowLeft
- Space
- Enter
- clic
- swipe mobile

## Présentation progressive

Certaines slides contiennent plusieurs étapes.

Le bouton suivant doit d'abord révéler la prochaine étape avant de changer de slide.

Exemple :

1. Une communauté peut être grande…
2. …et silencieuse.
3. Slide suivante.

---

# 8. EFFETS TECHNIQUES

## CSS

Utiliser :

- transform ;
- opacity ;
- clip-path avec prudence ;
- CSS variables ;
- transitions ;
- keyframes.

## JavaScript

Créer un moteur simple basé sur :

- slide active ;
- animation step active ;
- direction ;
- keyboard events.

## Performance

Éviter :

- animations permanentes coûteuses ;
- blur excessif ;
- canvas inutile ;
- dépendances lourdes.

Cible : fluidité sur ordinateur moyen.

# 10. MOTEUR DE PRÉSENTATION

Chaque slide possède :

- un identifiant ;
- une catégorie narrative ;
- un nombre d'étapes ;
- une animation d'entrée ;
- une animation de sortie.

Concept :

```text
SLIDE
 ├── ENTER
 ├── STEP 1
 ├── STEP 2
 ├── STEP 3
 └── EXIT
```

Le moteur doit empêcher une navigation brutale lorsque la slide contient encore des étapes narratives non révélées.

---

# 11. ACCESSIBILITÉ

Prévoir :

- contraste élevé ;
- navigation clavier ;
- `prefers-reduced-motion` ;
- taille de texte responsive ;
- pas d'information essentielle uniquement transmise par la couleur.

---

# 12. RÈGLES DE QUALITÉ

## Interdit

- transitions PowerPoint classiques ;
- animations bounce ;
- rotation inutile ;
- 15 éléments animés simultanément ;
- texte trop petit ;
- gradients décoratifs excessifs ;
- glassmorphism partout.

## Obligatoire

- rythme ;
- respiration ;
- contraste ;
- intention ;
- fluidité ;
- cohérence narrative.

# 13. PROMPT DE DÉVELOPPEMENT — MASTER BRIEF

> Construis une présentation web immersive en HTML, CSS et JavaScript pour **HashCode Reboot × Founder Lab**.
>
> La présentation doit être une expérience narrative premium inspirée du rythme des conférences TEDx et des grandes keynotes technologiques : minimalisme, espace négatif, typographie massive, storytelling progressif et animations cinématiques.

>
