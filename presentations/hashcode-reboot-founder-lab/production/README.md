# Production — HashCode Reboot × Founder Lab

Présentation web premium construite en HTML, CSS et JavaScript.

## Lancer

Ouvrir `index.html` dans un navigateur moderne.

## Contrôles

- → / Espace / Entrée : avancer
- ← : revenir
- clic à droite : avancer
- clic à gauche : revenir
- F : plein écran
- swipe : navigation mobile

## Architecture

- `index.html` : shell
- `styles.css` : design system et animations
- `app.js` : moteur de présentation, étapes narratives et navigation

## Prochaine itération

1. intégrer le logo officiel HashCode Reboot ;
2. enrichir chaque slide avec les étapes du storyboard complet ;
3. ajouter un mode présentateur ;
4. ajouter notes orateur ;
5. intégrer des effets cinématiques supplémentaires sans compromettre les performances.
