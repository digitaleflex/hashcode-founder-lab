# Guide de démarrage

## 1. À quoi sert ce dépôt ?

Ce dépôt est la **source versionnée des contenus pédagogiques professionnels** du HashCode Founder Lab.

Il ne sert pas à gérer les présences, les rendez-vous ou les tâches quotidiennes. Ces éléments sont pilotés dans Notion.

## 2. Les trois environnements

### Notion — Pilotage
Utilisé pour :
- programmes actifs ;
- apprenants ;
- planning ;
- suivi des séances ;
- livrables ;
- feedback opérationnel.

### GitHub — Source de contenu
Utilisé pour :
- cours ;
- exercices ;
- activités ;
- modèles ;
- évaluations ;
- documentation pédagogique ;
- historique des modifications.

### Founder Lab — Expérience apprenant
L'apprenant doit pouvoir :
- apprendre ;
- pratiquer ;
- produire ;
- recevoir du feedback ;
- progresser.

## 3. Commencer à travailler

1. Identifier le parcours concerné dans `curricula/`.
2. Lire son `README.md`.
3. Vérifier le `syllabus.md`.
4. Identifier la séance ou le livrable concerné.
5. Modifier uniquement le contenu nécessaire.
6. Relire avant validation.
7. Enregistrer une modification avec un message de commit clair.

## 4. Règle anti-suringénierie

Ne créez pas un fichier, un dossier ou un standard sans besoin concret.

Avant tout ajout, poser la question :

> **Quelle valeur cet élément apporte-t-il à l'apprenant, au formateur ou au système ?**
