# Guide de contribution au contenu

## Objectif

Garantir que les contenus du Founder Lab restent utiles, cohérents et réutilisables.

## Avant de créer un contenu

Définir :

- le besoin ;
- le public ;
- la compétence visée ;
- le résultat attendu ;
- le contexte d'utilisation.

## Structure pédagogique

Un contenu doit répondre à une fonction identifiable :

- expliquer ;
- illustrer ;
- faire pratiquer ;
- faire produire ;
- évaluer.

## Workflow

`Besoin → Proposition → Première version → Review → Amélioration → Validation`

## Checklist avant validation

- L'objectif est-il clair ?
- Le public est-il identifié ?
- Le contenu est-il compréhensible ?
- Un exemple est-il nécessaire ?
- Une pratique est-elle prévue ?
- Le résultat attendu est-il observable ?
- Le contenu crée-t-il une valeur réelle ?

## Messages de commit

Utiliser des messages explicites.

Exemples :

`feat(hfl-kdq-01): add S01 framing exercises`

`docs(s01): clarify scope definition`

`fix(assessment): correct validation criteria`
