# Contribuer au HashCode Founder Lab

Merci de contribuer au développement des parcours et ressources pédagogiques.

## Principes

- créer de la valeur avant de créer de la complexité ;
- privilégier les besoins réels ;
- écrire clairement ;
- séparer faits, hypothèses et recommandations ;
- tester les contenus avec de vrais utilisateurs ;
- améliorer continuellement.

## Processus

1. Identifier le besoin.
2. Vérifier le contenu existant.
3. Proposer une modification ciblée.
4. Produire une première version.
5. Faire reviewer.
6. Corriger.
7. Valider.

## Ce que nous évitons

- fichiers vides ;
- documentation décorative ;
- duplication inutile ;
- standards sans usage concret ;
- architecture plus complexe que le besoin.

## Definition of Done

Un contenu est terminé lorsqu'il est :

- compréhensible ;
- utilisable ;
- cohérent avec le parcours ;
- relu ;
- associé à un objectif ou besoin réel.
